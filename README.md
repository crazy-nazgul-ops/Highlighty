# Highlighty

Highlighty is a browser editor for marking up a manuscript. Paste a draft, color passages in stacked highlight layers, and leave notes in the margin. The file stays on your machine.

It is meant for a writer or editor who wants to read a draft the way they would with highlighters and margin notes, then pull those marks back out without losing the original text.

## What you can do

- Paste or type a manuscript, with a document title and your name for comments.
- Apply italic, bold, center, and indent.
- Add highlight layers, rename them, recolor them, and set how strong the color is.
- Stack layers so the top row paints over the rows below it. Hide a layer when you want it out of the way.
- Highlight a selection, or turn on Paint and drag across text. Applying a layer again clears only that color.
- Attach a comment to a selection, edit it in the margin, and show or hide comments.
- Save and open a `.json` file that keeps the text, layers, and comments together.
- Export the excerpts from one layer as text.
- Export a PDF through the print dialog.

## Run it

```bash
npm install
npm run dev
```
